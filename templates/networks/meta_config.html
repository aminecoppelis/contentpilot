Comprendre les identifiants OAuth

La plateforme utilise des identifiants techniques OAuth. Aucun compte Facebook ou Instagram global n'est enregistré ici.

Facebook App ID
Identifiant technique de l'application OAuth utilisée pour connecter directement les Pages Facebook des utilisateurs.

Facebook Configuration ID
Identifiant du parcours Facebook Login for Business. Ce n'est pas un App ID et il n'a pas de secret associé.

Instagram App ID
Identifiant technique utilisé par Instagram Login direct, avec son Instagram App Secret.

Pour remplacer un App ID, modifie le champ correspondant. Pour remplacer un App Secret, saisis le nouveau secret dans le champ vide : l'ancien secret n'est jamais affiché dans le navigateur.

Configure uniquement les applications OAuth techniques. Les utilisateurs se connectent ensuite directement à Facebook ou Instagram dans Mes réseaux ; aucun compte social global n'est utilisé et un jeton chiffré distinct est enregistré pour chaque compte.
